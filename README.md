# Atlas CS2: published read-only snapshot

This separate public repository contains the approved static Atlas export and public reference images. It contains no source controls, trading actions, credentials, browser sessions, Telegram identifiers or databases.

The page displays its snapshot time. Publication is separate from source collection; when the owner's application or Mac is off, the snapshot cannot update. Saved selected history is available with pagination and an older-history switch. History and market coverage remain partial. Expired asks are not current offers; purchase availability and settlement are not verified.

Pages contain `noindex,nofollow,noarchive,noimageindex`. This requests search-engine exclusion and does not restrict access to this public repository or page.
